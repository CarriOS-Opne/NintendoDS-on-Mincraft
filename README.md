# Octobus Mincraft — 닌텐도 DS Lite 홈브루

마인크래프트 포켓 에디션(0.x 알파) 감성의 3D 블록 게임입니다. DS Lite 실기에서 플래시카트로 실행하는 **홈브루(homebrew, 비공식 자작 소프트웨어)** 이고, 텍스처는 보내주신 텍스처팩(Mc-texchy)에서 뽑은 BMP 데이터를 씁니다.

## 실행

1. `OctobusMincraft.nds`를 플래시카트(R4 등) SD 카드에 복사해서 실행합니다.
2. PC에서 확인할 때는 melonDS나 DeSmuME 에뮬레이터로 열면 됩니다(에뮬레이터에서는 보통 저장이 안 됩니다).

## 켜지지 않을 때

- v0.3에서 R4 계열 카드가 **SD 카드 확인 중에 멈추던 문제**가 있었습니다.
  - 원인: 속도 최적화를 하면서 켠 하드웨어 **타이머**가 플래시카트 SD 드라이버(DLDI)가 쓰는 타이머와 겹쳤습니다.
  - v0.4부터는 **속도 최적화를 전부 껐습니다.** 게임이 하드웨어 타이머를 아예 건드리지 않으므로, SD 드라이버는 v0.2 때처럼 혼자 타이머를 씁니다.
- 켤 때 아래 화면의 **1/4~4/4**는 SD 확인 단계입니다(1 드라이버 시작, 2 카드 확인, 3 파일 시스템, 4 저장 파일).
- 그래도 멈추면 **SELECT를 누른 채 다시 켜세요.** 저장만 끄고 켜지는 안전 모드입니다.

## 저장

- 일시정지 메뉴의 **저장하기**나 **저장하고 나가기**를 누르면 SD 카드 맨 위 폴더(루트)에 `OCTOMC.SAV`(1.25MB)가 생깁니다. 월드, 위치, 체력·배고픔·경험치, 인벤토리, 시간, 설정이 모두 들어갑니다.
- 저장이 있으면 **게임 시작**을 눌렀을 때 **이어하기 / 새 월드**를 고를 수 있습니다.
- 설정(언어, 시야각 등)은 설정 화면에서 **완료**를 누를 때 저장됩니다.
- SD 카드에는 **DLDI**로 접근합니다. DLDI는 플래시카트마다 다른 SD 드라이버를 게임 안의 빈칸에 끼워 넣는 방식이고, 대부분의 플래시카트 메뉴가 실행할 때 자동으로 끼워 줍니다(이것을 "DLDI 패치"라고 합니다).
- 화면에 **저장 장치 없음 (DLDI)**이 뜨면 자동 패치가 안 된 것입니다. 이때는 PC에서 dlditool과 내 플래시카트용 `.dldi` 파일로 패치하면 됩니다.
- FAT16과 FAT32 SD 카드를 지원합니다(FAT12와 exFAT는 안 됩니다).

## 메인화면 (3DS 에디션처럼)

- **위 화면**: 실제 월드가 천천히 돌아가는 3D 배경(파노라마) 위에 로고, `NINTENDO DS LITE EDITION` 문구, 노란 스플래시 문구가 뜹니다.
- **아래 화면**: 흐릿한 나무 방 배경에 **START 버튼을 누르세요**가 뜹니다. 누르면 **게임하기 / 도움말 및 설정** 메뉴가 나옵니다.
- **게임하기**를 누르면 저장된 월드(모드 표시)와 **새로 만들기**가 나옵니다. 새로 만들 때 **게임 모드**와 시드를 고릅니다.

## 게임 모드

| 모드 | 내용 |
|---|---|
| 서바이벌 | 기존과 같습니다. |
| 크리에이티브 | 체력·배고픔이 없고, 블록이 줄지 않으며, 바로 부서집니다. **A를 두 번** 누르면 비행을 켜고 끕니다(비행 중 A는 위, B는 아래). X나 상자 버튼을 누르면 모든 블록과 아이템이 있는 **크리에이티브 인벤토리**가 열립니다. |
| 하드코어 | 받는 데미지가 1.5배이고 목숨은 하나입니다. 하트 모양이 다르고, 죽으면 **월드가 삭제**됩니다. |
| 관전자 | 벽을 그대로 통과해서 날아다니기만 하는 모드입니다. 블록을 놓거나 캐거나 몹을 때릴 수 없고, 데미지도 전혀 받지 않으며 몹이 아예 공격 대상으로 삼지 않습니다. 체력·배고픔 바도 뜨지 않습니다. |

## 무한 맵과 차원

- 맵 끝이 없습니다. 16×64×16 크기의 **청크**를 내 주변 8×8칸만 메모리에 올려 두고, 걸어가면 앞쪽은 새로 만들고(**청크 스트리밍**) 뒤쪽은 내립니다.
- 지형은 시드로 항상 똑같이 만들어지므로, **내가 바꾼 청크만** 압축해서 저장소에 보관합니다(RAM 600KB, 저장할 때 SD에 기록).
- **바이옴**: 숲·평원, **사막**(모래, 사암, 선인장), 바다가 있습니다.
- **마을**: 집(판자, 통나무 기둥, 유리창, 문, 침대, 제작대), 우물, 자갈길이 있고 **주민**과 **철 골렘**이 삽니다. 처음 시작하면 마을 옆에서 태어납니다.
- **네더 차원문**: 흑요석으로 틀(안쪽 가로 2~21칸, 세로 3~21칸, 모서리는 없어도 됨)을 세우고 **부싯돌과 부시**로 틀 안에 불을 붙이면 켜집니다. 퍼지던 불이 틀 안에 들어가도 켜집니다. 틀을 깨면 차원문 전체가 꺼집니다. 2.5초 서 있으면 네더로 갑니다. 네더는 좌표가 1/8로 줄어듭니다. 흑요석은 들판의 **폐허 차원문**에서 얻거나, 다이아몬드 곡괭이로 캘 수 있습니다.
- **네더**: 네더랙, 용암 바다, 영혼 모래, 발광석이 있고 **피글린**과 **호글린**이 나옵니다.
- **엔더 유적**: 이끼 낀 석재 벽돌 폐허 안에 **켜져 있는 엔드 차원문**이 있습니다. 지형 조건 없이 **청크마다 무조건 4% 확률**로 생깁니다(바다 한가운데라도 생길 수 있어요).
- **엔드**: 엔드 스톤 섬, 흑요석 기둥 8개, **엔더맨**, 그리고 **엔더 드래곤**이 있습니다. 드래곤은 섬 위를 돌다가 덤벼듭니다. 물리치면 가운데에 돌아가는 차원문이 열립니다.

## 새 블록과 아이템

- **침대**(양털 3 + 판자 3, 한 칸에 1개만): 위키처럼 **2칸짜리**입니다. 누른 칸에 발쪽, 내가 보는 방향 앞칸에 머리(베개)쪽이 놓입니다. 바닥 두 칸이 모두 있어야 놓입니다. 위에 올라설 수 있고(높이 9/16칸), 한쪽을 부수면 둘 다 없어지고 침대 1개가 나옵니다.
  - 누르면 리스폰 위치가 정해지고("리스폰 위치를 정했어요"), 밤이 아니면 "밤에만 잘 수 있어요"가 뜹니다.
  - 침대에서 가로 8칸·세로 5칸 안에 몬스터가 있으면 "지금은 쉴 수 없어요"가 뜹니다.
  - 네더나 엔드에서 쓰면 폭발하고 주변에 불이 붙습니다.
- **문**(판자 6 → 3개): 누르면 열리고 닫힙니다. 문은 얇은 판이라 닫혀 있으면 그 판만 막고, 열린 문 옆으로는 지나갈 수 있습니다.
- **불**(v0.4, 위키 기준)
  - 부싯돌과 부시를 **단단한 블록 위**나 **불에 타는 블록의 옆면**에 쓰면 불이 붙습니다. 쓸 때마다 내구도가 1 줄고, 64번 쓰면 부서집니다.
  - **네더랙 위의 불은 꺼지지 않습니다.** 다른 블록 위의 불은 시간이 지나면 꺼집니다.
  - 불에 타는 블록: **판자, 통나무, 나뭇잎, 양털.** 불은 옆(대각선 포함)·1칸 아래·4칸 위까지 퍼지고, 타는 블록은 타서 없어집니다.
  - 물 옆에서는 꺼지고, 불이 붙은 블록 면을 때리면 꺼집니다. 불 속에 서 있으면 데미지를 입고, 물에 들어가면 꺼집니다.
  - **크리퍼에게 쓰면 바로 터집니다**(멈출 수 없음).
- **유리**(모래 + 석탄), **사암**(모래 4), **석재 벽돌**(돌 4)
- **부싯돌**: 자갈을 캐면 가끔 나옵니다.
- **부싯돌과 부시**: 철 + 부싯돌
- **양털**: 양을 잡으면 나옵니다.
- **엔더 드래곤**: 이번 텍스처팩의 `images.png`가 엔더 드래곤 그림이어서 엔드에 넣었습니다.
- **에메랄드 광석/에메랄드**: 보내주신 텍스처팩의 광석 사진에서 초록색 샘플을 뽑아 새로 넣었습니다. 캐면 에메랄드 1개가 나옵니다(철 곡괭이 이상 필요).
- **엔더의 눈**: 역시 보내주신 텍스처에서 아이콘을 뽑았습니다. 엔더맨을 잡으면 1/3 확률로 떨어집니다. 지금은 들고 다니는 아이템일 뿐, 차원문을 완성하는 기능은 없습니다(유적의 차원문은 이미 켜진 채로 생겨요).
- **광석 생성 확률**(청크 1개 기준, 터지면 그 청크 어딘가에 광맥 하나가 생깁니다): 석탄 20%, 철 12%, 금 3%, 레드스톤 20%(바다 높이 -12 아래에서만), 에메랄드 5%, 다이아몬드 0.4%(대신 터지면 광맥이 2~4개 한꺼번에 생깁니다).

## 최적화 (v0.4: 파일 크기 최적화)

- `.nds` 파일 크기: **605KB → 약 300KB** (절반)
  - **블록 아이콘을 실행 중에 그립니다.** 전에는 블록마다 24×24, 48×48 아이콘 그림을 미리 만들어 파일에 넣었는데(약 250KB), 이제는 블록 텍스처로 그 자리에서 작은 입체 상자를 그립니다. 그래서 BMP를 바꾸면 아이콘도 같이 바뀝니다.
  - **메인화면 배경을 절반 크기**(128×96)로 넣고 2배로 늘려 그립니다. 원래 흐릿한 그림이라 차이가 거의 없습니다.
  - 코드는 전부 **Thumb 모드 + `-Os`**(크기 우선 컴파일)로 만듭니다. Thumb는 ARM9의 짧은 명령어 형식이라 코드가 작아집니다.
- v0.3에 넣었던 **속도 최적화는 모두 껐습니다**: 하드웨어 타이머로 시간을 재던 것, ARM 모드 컴파일, DTCM(초고속 메모리)에 표를 두던 것. 청크 불러오기와 메시 만들기는 프레임마다 정해진 개수만 합니다.
- 메시 메모리는 **first-fit 할당기**로 재사용하고, 폴리곤 예산은 **1600개**(시야 거리 48칸)입니다. 요청하신 대로 그래픽 수준을 조금(전엔 1400개/40칸) 올렸습니다.

## 화면 구성

**위 화면** (보내주신 3DS 사진과 같은 배치)
- 맨 위: 경험치 바(`gfx/hud/xp_*.bmp`)
- 바로 아래 왼쪽: 하트 10개(`heart_*.bmp`), 가운데: 레벨 숫자, 오른쪽: 배고픔 10개(`food_*.bmp`)
- 가운데: 조준점(크로스헤어), 오른쪽 아래: 손에 든 아이템/블록

**아래 화면** (원래 지도가 있던 자리를 둘러보기 패드로 바꿈)
- 맨 위: 핫바 9칸(`slot.bmp`, `slot_selected.bmp`), 그 아래 좌표 줄
- 둘러보기(Look) 패드: 드래그하면 시야 회전, 짧게 탭하면 블록 놓기/먹기/공격, 누른 채로 있으면 캐기
- 패드 아래: **시야각(FOV) 슬라이더** 50~110
- 오른쪽 버튼 3개: 상자 = 인벤토리, 제작대 = 제작, ‖ = 일시정지

## 게임 내용

- **블록**: 잔디, 흙, 돌, 조약돌, 모래, 나무, 나뭇잎, 판자, 제작대, 상자, 석탄·철·금·다이아·레드스톤·에메랄드 광석, 기반암, 물
- **서바이벌**: 체력·배고픔·경험치, 낙하 데미지, 배고픔이 18 이상이면 체력 회복, 0이 되면 굶주림 데미지, 사망 후 리스폰
- **물속 숨**: 머리가 물에 잠기면 배고픔 줄 아래에 방울 10개(하트 수와 같음)가 뜨고, 1초에 하나씩 줄어듭니다. 방울이 다 없어지면 1초에 체력이 1씩 깎입니다. 물 밖으로 나오면 금방 다시 찹니다.
- **낮과 밤**: 하루는 12분이고, 해와 달이 움직이며 밤에는 세상이 어두워집니다. 좀비와 크리퍼는 **밤에만** 나오고, 좀비는 해가 뜨면 불에 타서 사라집니다.
- **캐기 표시**: 캐는 동안 블록에 금(크랙)이 10단계로 번집니다.
- **도구 등급**: 돌은 나무 곡괭이 이상, 철은 돌 곡괭이 이상, 금·다이아·레드스톤은 철 곡괭이 이상이 있어야 드롭됩니다. 도구에는 내구도가 있습니다.
- **제작**: 판자, 막대기, 제작대는 어디서나 만들 수 있고, 상자와 도구는 제작대가 주변 4칸 안에 있어야 합니다.
- **몹**: 돼지(때리면 돼지고기), 좀비(따라와서 공격), 크리퍼(가까이 오면 깜빡이다가 폭발해서 블록을 부숨). 옵션에서 Peaceful로 바꾸면 적대 몹이 나오지 않습니다.
- **시작 아이템**: 사과 2개, 빵 1개

## 언어

설정 → **언어** 버튼을 누를 때마다 English → 한국어 → 中文 → 日本語 → 조선어 순서로 바뀝니다.
- 조선어를 고르면 타이틀 로고가 **탄광공예**로 바뀝니다(이스터 에그).
- 모든 문장은 `lang/strings.txt` 한 파일에 언어별로 들어 있으니, 고치고 다시 빌드하면 됩니다.
- 한글·한자·가나는 **Unifont**(16×16 픽셀 글꼴)에서 실제로 쓴 글자만 뽑아 넣습니다(`tools/make_lang.py`).

## 이미지(BMP) 바꾸기

모든 그림은 `gfx/` 폴더의 BMP 파일입니다. 그림판 같은 프로그램으로 고치고 다시 빌드하면 게임에 들어갑니다. **마젠타색(255, 0, 255)이 투명**입니다.

| 폴더 | 내용 | 크기 |
|---|---|---|
| `gfx/blocks/` | 블록 면 텍스처(잔디 윗면/옆면 등) | 16×16 |
| `gfx/items/` | 아이템 아이콘(곡괭이, 검, 음식 등) | 16×16 |
| `gfx/mobs/` | 돼지/좀비/크리퍼 얼굴·몸통 | 16×16 |
| `gfx/hud/` | 하트, 배고픔, 경험치 바, 핫바 칸, 조준점, 버튼 아이콘 | 각 파일 크기 그대로 |
| `gfx/ui/` | 타이틀 로고(`logo.bmp`, 조선어용 `logo_kp.bmp`), 글꼴(6×11 칸, ASCII) | 각 파일 크기 그대로 |
| `gfx/fx/` | 캐기 금 10단계(`destroy_0`~`9`) | 16×16 |

- 핫바와 손에 드는 블록 아이콘은 블록 텍스처로 **자동 생성**됩니다(아이소메트릭 큐브).
- 텍스처팩을 통째로 바꾸려면 `python tools/extract_texpack.py <텍스처팩 폴더> gfx`와 `python tools/extract_texpack2.py <텍스처팩 폴더> gfx`를 차례로 실행하면 됩니다(같은 전개도 형식일 때만).

## 빌드

SDK(devkitPro/BlocksDS)가 **필요 없습니다**. DS 시작 코드, 링커 스크립트, ARM7 코드, .nds 패커를 직접 만들어 넣었습니다.

- 준비물: **Arm GNU Toolchain**(`arm-none-eabi-gcc`)과 Python 3 + Pillow(`pip install pillow`)
- 문장을 고쳤을 때 글꼴을 다시 뽑으려면 `unifont.otf`가 필요합니다. 경로는 `python tools/make_lang.py lang/strings.txt src/arm9 <unifont.otf 경로>`로 지정합니다. 문장을 고치지 않았다면 이미 만들어진 `src/arm9/lang.c`가 쓰입니다.
- Windows: `build.bat` 실행
- Linux / WSL / macOS: `make`

## 구조 (용어 정리)

- `src/arm9/` — 게임 본체. DS에는 CPU가 두 개인데, ARM9은 메인 CPU입니다.
  - `world.c` — 청크 스트리밍, 수정 청크 저장소, **그리디 메싱(greedy meshing)**: 같은 텍스처의 인접한 면을 큰 사각형 하나로 합쳐 폴리곤 수를 줄이는 기법
  - `gen.c` — 시드 기반 지형·구조물 생성(오버월드·네더·엔드, 마을, 유적)
  - `render.c` — DS 3D 엔진 렌더링, **프러스텀 컬링(frustum culling)**: 화면 밖 청크를 그리지 않는 것, **폴리곤 예산(polygon budget)**: DS 하드웨어 한계(정점 6144개) 안에 맞추려고 가까운 청크부터 최대 1400개만 그림, 거리 안개(fog)
  - `entity.c` — 몹 AI와 박스 모델
  - `ui.c`, `gfx2d.c` — HUD와 아래 화면 UI, UTF-8 글자 그리기
  - `save.c`, `fat.c`, `dldi.s` — 저장. **DLDI 스텁(stub)**은 플래시카트가 SD 드라이버를 채워 넣는 32KB 빈칸이고, `fat.c`는 FAT16/FAT32를 읽고 쓰는 최소한의 **파일 시스템 드라이버**입니다. 월드는 **RLE 압축**(같은 블록이 이어지면 "블록, 개수"로 줄여 쓰는 방식)으로 보통 수백 KB로 줄어듭니다.
  - `fire.c` — 불(퍼짐, 꺼짐, 타는 블록, 데미지)
- `src/arm7/` — 보조 CPU(ARM7). X/Y 버튼과 터치스크린 값을 읽어 ARM9에 넘겨 줍니다.
- `tools/mknds.py` — .nds 롬 헤더와 아이콘(배너)을 만드는 패커(ndstool을 대신함)
- `tools/make_assets.py` — BMP를 C 배열로 바꾸는 변환기

## 알려진 제한

- 화로가 없어서 철·금 광석은 바로 주괴로 드롭되고, 돼지고기는 제작 화면에서 석탄 1개로 굽습니다.
- 상자 보관, 횃불·블록 조명은 아직 없습니다. 몹은 저장되지 않습니다.
- 마인크래프트 기능을 "전부" 넣지는 못했습니다. DS는 RAM 4MB, 폴리곤 약 2000개가 한계라서, 이번에는 요청하신 **문·침대·불·부싯돌과 부시·차원문**을 위키 규칙에 맞췄습니다. 레드스톤, 화로, 인챈트, 바이옴 수십 종 같은 큰 기능은 들어가 있지 않습니다.
- 속도 최적화를 끈 만큼 실기에서는 v0.3보다 청크가 조금 느리게 나타날 수 있습니다.
- 게임 전체는 DeSmuME 에뮬레이터에서만 테스트했습니다. 저장 기능은 PC에서 FAT16/FAT32 디스크 이미지로 저장→불러오기를 검증했지만, 실제 플래시카트(DLDI)에서는 아직 돌려 보지 않았습니다.
